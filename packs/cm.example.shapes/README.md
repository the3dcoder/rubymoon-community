# Find the Shape

A tiny example pack: four gentle questions about circles, squares and triangles. It's here to copy when
you make your own pack, and it's a nice first game too.

- **Ages:** 3 to 5 (bands B1 to B3)
- **World:** Shapes
- **Items:** 4. Three "find the shape" questions and one yes-or-no question about a square's corners.

## Playing together

Before she presses a button, trace the edge of each shape on the screen with your finger and say what you
notice: "This one is round all the way. This one has pointy corners." Count the corners out loud together.
If she picks the wrong one, the hint is a good thing to read to her.
